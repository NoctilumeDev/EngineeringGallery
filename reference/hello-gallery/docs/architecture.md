# Architecture Notes

Hello Gallery exercises three presentation planes without entering the real project lifecycle.

## Showroom plane

The English landing page, preview, diagrams, and Chinese-edition route establish the visitor-facing reading order.

## Distribution demonstration

The Quick Start and version placement demonstrate how a future project can be obtained and run. They do not create a distributable project payload.

## Control demonstration

`REFERENCE_STATUS`, `ORIGIN.md`, and the reference verifier make the synthetic boundary observable and mechanically enforce the absence of project and catalog identities.

## Hard boundary

The specimen lives under `reference/`. Real projections live under `projects/`, and released exhibits acquire separate catalog records. There is no state transition from this specimen into those namespaces.
