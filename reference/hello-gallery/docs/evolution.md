# Evolution

## Why it exists

G1 established the Gallery's export, lock, qualification, and catalog contracts while the catalog was empty. The next presentation work needed realistic content, but no laboratory project had reached a suitable release boundary.

Hello Gallery solves that timing problem without weakening qualification. It acts as fixture data for the public room.

## When it may change

The specimen may change when the Gallery needs to test:

- a new public reading pattern;
- a different preview or diagram treatment;
- responsive behavior;
- provenance or limitation placement;
- a language-route presentation;
- a new reference-only negative check.

It must not change merely to imitate the current feature set of a real project.
