## 概览

Hello Gallery 是展厅自己的样板间。它用一份极小的合成内容，验证访客能否看懂项目、预览结果、找到 Quick Start、识别范围并追溯来源。

## 演示与预览

静态 Demo 展示三个平面：Showroom 负责理解，Distribution 负责获取和运行，Control 负责区分来源、资格、发布与路由状态。

## 当前范围

当前只有英文展陈结构、响应式静态 Demo、三张 SVG、中文派生页样板和边界校验。没有真实项目、产品 tag、GitHub Release、Catalog 记录或 Profile 路由。

## Quick Start

直接在现代浏览器打开 `../demo/index.html`。看到 `REFERENCE_SPECIMEN` 以及 `Showroom`、`Distribution`、`Control` 三张卡片，即完成本地展示检查。
