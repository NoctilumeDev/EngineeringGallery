# Reference Specimens

This namespace contains synthetic material used to exercise Engineering Gallery itself.

Reference specimens may demonstrate layout, documentation order, visual assets, language routing, and control checks. They are never project projections and are excluded from projection, candidate, catalog, and release counts.

## Available specimen

- [Hello Gallery](hello-gallery/README.md) — a complete showroom and responsive demo for validating the Gallery contract before the first real exhibit.

Every specimen must remain visibly marked `REFERENCE_SPECIMEN`.
