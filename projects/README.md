# Projects

This directory contains complete project projections under Gallery construction or release.

Empty placeholders and partial source dumps are not allowed. A candidate directory may appear only when it is a complete, reviewable projection with an exact origin, explicit export allowlist, generated projection lock, English documentation, and resolved licensing.

Directory presence does not prove qualification. A projection becomes a public English exhibit only after its exact-main Quick Start, project-scoped Release, Release readback, and catalog binding are complete. A verified Chinese-edition binding separately authorizes the Chinese Profile route. [`catalog/exhibits/`](../catalog/exhibits/README.md) is the qualification index.

The absence of a project here does not describe the maturity of its laboratory repository. It means only that a Gallery projection has not entered this release path.
